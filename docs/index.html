Quickstart

From zero to your first tailored CV in minutes.

No npm install. No build step. Just a GitHub template, your data, and an AI agent you already use.

bash 
# 1. Create your private repo from this template
$ gh repo create my-cv \
    --template tiennt0212/cv-builder \
    --private

# 2. Fill in your career data (once, ever)
$ cd my-cv && code personal-data/

# 3. Ask your AI agent to draft a CV
$ claude "Draft my CV for this role: [paste JD]"

# 4. Render to HTML + PDF
$ make render

FAQ

Common questions.

How does the AI know what to include? ▼
You paste the job description into your AI agent prompt. The agent reads both the JD and your personal-data/ folder, then decides which experience, skills, and achievements are most relevant for that role. The more detail you add to your data files, the better the tailoring.
Do I need to pay for an AI subscription? ▼
You need access to an AI agent like Claude Code, Cursor, or Gemini CLI — each has its own pricing. cv-builder itself is free and open-source (AGPL 3.0). If you already use an AI coding assistant, you're ready to go.
Can I customize the CV template or theme? ▼
Yes. The HTML renderer uses plain CSS templates that live in the repo — modify them directly, or ask your AI agent to build you a new theme. It's all static HTML + CSS, so there's no build system to fight with.
Will my personal data be sent to the cloud? ▼
Your personal-data/ folder is gitignored by default. However, when you prompt an AI agent, your data is sent to that agent's API as part of the context. Review your AI provider's privacy policy if this is a concern. cv-builder itself never uploads anything.
What's the license? ▼
cv-builder is licensed under AGPL 3.0. You can use it, fork it, and modify it freely. If you build a hosted service on top of it, you must also open-source that service. For personal use, there are no restrictions whatsoever.
